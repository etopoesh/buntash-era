# Бунташный век

Очная настольная игра по истории России XVI–XVII веков в виде веб-приложения. Ведущий ведёт общую панель и открывает ходы, игроки играют за свои рода в своих браузерах. Все действия синхронизируются через Firebase Realtime Database.

## О проекте

- 64 события: 60 игровых ходов и 4 очных собора (начало, два раунда и финал).
- Два сословия — бояре и дворяне — с разными стартовыми ресурсами и эффектами.
- Общие показатели державы: централизация и стабильность.
- Окно «Постройки» и усадьба с 12 постройками.
- Автоматический подсчёт большинства на глобальных событиях.
- Финальный экран с рейтингом родов, вердиктом державы и рекордами.

Полное описание правил и устройства кода — в [SPEC.md](SPEC.md).

## Запуск

Нужен любой статический HTTP-сервер — страницы загружают JSON через `fetch`, поэтому открытие через `file://` не подойдёт:

```powershell
python -m http.server 8741
```

Затем откройте `http://127.0.0.1:8741/index.html`. Для работы Firebase нужен доступ в интернет (SDK подключается с CDN).

## Живая и тестовая игра

- Обычный режим (`index.html`) пишет в ветку Firebase `buntash-state`.
- Режим с параметром `?test=1` (`index.html?test=1` или `test.html?test=1`) пишет в отдельную ветку `buntash-test` и не портит живую игру.
- Адрес базы: `https://buntash-era-default-rtdb.firebaseio.com`.

Финал наступает автоматически: последнее событие `assembly-final` имеет индекс 63. Ведущий попадает на него через ленту событий или стрелки ←/→, игрок доходит до экрана «Игра завершена» по кнопке «Далее →» на событии `itogi-60`. Отдельной кнопки «Завершить игру» нет.

## Тестирование

Полный тест запускается на странице:

```text
http://127.0.0.1:8741/test.html?test=1
```

Он проверяет загрузку данных, все кнопки ведущего и игрока, применение эффектов, покупку построек, защиту от двойного нажатия, большинство 2:1 и 1:1:1, прохождение всех родов до финала. Результат виден в панели на странице и в `window.__E2E_RESULT` (поля `total`, `failed`, `ok`). Ожидаемый результат: `PASS 408 / FAIL 0`.

Быстрая проверка только большинства:

```text
http://127.0.0.1:8741/test.html?test=1&only=majority
```

Проверка данных из командной строки:

```powershell
node tools/lint-events.js
```

Успешный вывод: `LINT-OK events.json`.

## Обновление и кэш

Версия подставлена в адреса подключаемых файлов в `index.html`, `test.html` и `final-view.html`. При изменении `events.json` или `buildings.json` поднимите версию: `firebase-init.js` берёт её из параметра `?v=` у своего тега `<script>` и добавляет к запросам JSON, чтобы браузер не показывал старые тексты.
